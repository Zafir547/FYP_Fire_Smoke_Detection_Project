# The Aegis: AI-Powered Fire and Smoke Detection System

I successfully built a real-time Fire and Smoke detection system using Computer Vision and Deep Learning.

Project Highlights:
- Real-time fire and smoke detection from Image, Video and CCTV otherwise live camera feed
- Built using YOLOv8s model Ultralytics
- Web-based interactive dashboard using Streamlit
- Live camera support via browser works on both laptop and mobile
- Instant visual alerts and logging system

Even though I didn't get enough time to clean the dataset properly planning to improve dataset quality soon, the model is already detecting smoke and fire in real-time.

This project strengthened my skills in:
→ Deep Learning (YOLO)  
→ Computer Vision (OpenCV)  
→ Python & Streamlit Dashboard Development
